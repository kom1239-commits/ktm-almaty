## Notes for KTM (vanilla HTML/CSS, not React/Tailwind)

The taste-skill / soft-skill / gpt-tasteskill assume React + Tailwind by
default. Treat their stack-specific rules (RSC, `text-4xl`, etc.) as
non-binding for KTM — but apply their *design principles* (typography,
color calibration, anti-AI-purple, asymmetric layout, motion budgets).

For KTM's actual code edits, **redesign-skill** is the best match: it is
framework-agnostic and walks through audit-then-fix on existing
codebases.
